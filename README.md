# OKIE HVAC

Business website for OKIE HVAC — a heating, cooling, and air quality company serving Stillwater, OK and surrounding areas.

## Tech Stack

- React 19
- Vite 7
- React Router 7
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
