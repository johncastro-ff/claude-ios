# Dandelion Promotions

Premium Meta ads agency for advanced aesthetic med spas. We fill your treatment calendar with high-ticket patients.

## What's Here

- **Agency Website** — React storefront with services, pricing, testimonials, and booking
- **Brand Style Guide** — Full identity system (colors, typography, tone, visual guidelines)
- **Strategy & Tactics Deck** — Operational playbook for med spa Meta advertising

## Tech Stack

- React 19
- Vite 7
- React Router 7
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

Opens at [http://localhost:5173](http://localhost:5173)

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
